# LockLab APK (no Android Studio needed)
1. Create a free GitHub account and a new empty repository.
2. Upload ALL files from this folder (keep the .github folder).
3. Open the Actions tab > Build APK > wait ~5 minutes.
4. Open the finished run, download "LockLab-apk", unzip, and install app-debug.apk on your phone (allow "Install unknown apps").
